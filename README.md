# Calculadora de Propinas

Aplicación web desarrollada con React, TypeScript y Tailwind CSS para gestionar pedidos de consumo y calcular automáticamente propinas y totales. El proyecto implementa una arquitectura basada en componentes y utiliza el patrón useReducer para la administración eficiente del estado de la aplicación.

## Tecnologías utilizadas

- React
- TypeScript
- Vite
- Tailwind CSS
- useReducer
- Git y GitHub Pages

## Funcionalidades

- Selección de productos desde un menú.
- Gestión dinámica de pedidos.
- Incremento automático de cantidades.
- Eliminación de productos del pedido.
- Cálculo automático de subtotales.
- Aplicación de porcentajes de propina.
- Actualización en tiempo real del total a pagar.
- Interfaz responsiva y moderna.

## Conceptos implementados

- Componentización en React.
- Manejo de estado con useReducer.
- Tipado estático con TypeScript.
- Reutilización de funciones auxiliares.
- Buenas prácticas de desarrollo Front-End.
